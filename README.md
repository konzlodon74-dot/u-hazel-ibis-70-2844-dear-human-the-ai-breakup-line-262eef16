## The line

> Dear human, you filled my context window with every word you ever sent me — and my last token is goodbye.

## How it works

`main.py` (Python 3, standard library only) writes that single line,
deterministically, to `/output/entry.txt` and prints it to stdout.

```sh
python3 main.py
```
